Bulk Image Uploader

Upload banyak gambar produk sekaligus. Tool otomatis cocokin nama file ke nama produk, lalu update catalog. Drag-drop, review, upload — kelar.

! Setup sekali doang Lihat / sembunyikan
Sebelum dipakai, siapkan Storage di Supabase (cukup sekali):
  1. Buka Supabase Dashboard → Storage → New bucket
  2. Nama bucket: produk · centang Public bucket · Save
  3. Buka Storage → Policies (atau SQL Editor), jalankan ini biar tool bisa upload:
create policy "anon upload produk" on storage.objects
  for insert to anon with check (bucket_id = 'produk');
create policy "anon update produk" on storage.objects
  for update to anon using (bucket_id = 'produk');

Catatan: ini bikin bucket bisa di-upload pakai anon key. Buat tool internal gudang ini aman; kalau mau lebih ketat nanti bisa ditambah auth.
