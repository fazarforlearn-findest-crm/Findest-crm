Step 1: Export Data dari Supabase Lama

Klik tombol untuk membaca semua tabel dan data dari project FindestSport (sfindest@gmail.com). Proses ini hanya MEMBACA, tidak mengubah apapun.

Step 2: SQL Script

SQL ini berisi CREATE TABLE + INSERT untuk semua data. Copy dan paste ke SQL Editor di Supabase baru (fazarforlearn).

Step 3: Paste di Supabase Baru

Ikuti langkah ini:
1. Buka project Findest di Supabase (fazarforlearn@gmail.com)
2. Klik SQL Editor di sidebar kiri
3. Klik "+ New query"
4. Paste Schema dulu (CREATE TABLE) → klik Run
5. Setelah berhasil, Paste Data (INSERT) → klik Run
6. Cek di Table Editor apakah data sudah muncul

PENTING: Jalankan Schema (CREATE TABLE) DULU, baru Data (INSERT). Jangan digabung karena bisa timeout.
